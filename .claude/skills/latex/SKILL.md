# LaTeX (papers and slides)

Slides are Beamer, so they are LaTeX too — same compile loop, same bibliography.
Only the content transformation differs (see below).

## Build

```
cd projects/<name> && tectonic main.tex     # -> main.pdf
```

The `PostToolUse` hook in `.claude/settings.json` runs this automatically after
any `.tex` edit and feeds errors back. Notes:

- **The first ever compile is slow** (~1 min) — Tectonic downloads its package
  bundle. Later builds are seconds. Don't assume it hung.
- Read the error, not just the last line. `! LaTeX Error:` and `l.<n>` lines
  point at the real cause; a missing `$` shows up hundreds of lines later.
- A missing package is not an error to work around — Tectonic fetches it on
  demand. If it genuinely can't, say so rather than rewriting the math.

## Bibliography — natbib, not biblatex

**Tectonic bundles classic `bibtex` and cannot run `biber`.** So biblatex is out.
Use natbib, which every ML venue style (NeurIPS/ICML/ACL) already ships:

```latex
\usepackage[numbers]{natbib}
...
\bibliographystyle{plainnat}
\bibliography{../../refs}    % note: no .bib extension
```

`\citep{key}` for parenthetical, `\citet{key}` for inline. Keys come from
`refs.bib`, added by `python3 bin/papers.py bib <id>` — never hand-written.

## Structure

`main.tex` stays readable: preamble, then `\input{}` per section once the paper
outgrows one screen. Figures in `figures/`, generated by scripts in
`experiments/` so a number in the paper can always be traced to code.

## Rules

- **Every number in the paper comes from a file in `experiments/`.** If you
  cannot point at the script that produced it, it does not go in a table.
- **Fix the source of a build error, not the symptom.** Wrapping a broken
  environment in `\resizebox` to make it compile hides the real problem.
- Don't add packages speculatively. Add one when a specific command needs it.
- Keep one sentence per line in the source — it makes diffs readable.

## Slides from a paper

Beamer deck, not the paper reflowed. Per slide: one claim as the title, one
visual as the body. Method sections become a build-up across several frames;
related work usually becomes one slide or none. Reuse `figures/` directly and
cite with the same `refs.bib`.

```latex
\documentclass{beamer}
\usepackage[numbers]{natbib}
\begin{document}
\begin{frame}{One claim per slide}
  \includegraphics[width=\linewidth]{../figures/result.pdf}
\end{frame}
\end{document}
```
